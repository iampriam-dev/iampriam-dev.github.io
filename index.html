🎯 What This Tool Does

team-formation helps educators and staff assign every student to a project team fairly and efficiently. It takes the Excel workbook you already use to collect student preferences and uses a powerful solver to create the best possible team assignments. You get:

  • Every student placed – no one is left without a team.
  • Strict priorities respected – the assignments follow the rules you set.
  • Proven-optimal results – the solver finds the best solution mathematically possible.
  • An audit report – see exactly why each student was placed where they are.

🚀 Why Use This Tool

Forming student teams by hand is slow and often unfair. This tool removes the guesswork. It works with your existing staff Excel workbook, so you don't need to learn new software. The solver handles the complex math behind the scenes, while you get clear, reliable team assignments you can trust. Whether you have 30 students or 300, the process is fast, transparent, and evidence-based.

⚙️ Key Features

  • Excel workbook input – use the familiar spreadsheet format you already have.
  • Strict priority handling – assign importance to student preferences, project capacities, or other rules.
  • Proven-optimal solver – powered by Google OR-Tools CP-SAT, it guarantees the best possible team formation.
  • Audit report – a detailed record of how each placement decision was made.
  • Works on Windows – designed to run on your Windows computer.
  • No programming required – just download, run, and use your Excel workbook.

📋 How It Works

The process is straightforward and designed for non-technical users:

  1. Prepare your Excel workbook – fill in student names, project choices, and any rules (like team size or priority levels).
  2. Run the application – the solver reads your workbook and calculates the optimal team assignments.
  3. Review the results – you get a clear output with every student assigned to a team, plus an audit report explaining the decisions.

There are no complex settings or hidden steps. The tool is built to be used by staff, not programmers.

💡 What You Need

  • Your staff Excel workbook with student data and project preferences.
  • An internet connection to download the application from the link below.
